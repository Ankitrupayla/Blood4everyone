# 🩸 Blood4Everyone

**Blood4Everyone** is a full-stack blood donation platform built to connect blood donors, recipients, volunteers, and blood banks across India. The website enables users to register, request, donate, and locate nearby blood banks with real-time updates and a user-friendly interface.

## 📌 Features

- 🔍 Search & filter registered **blood donors**
- 🆘 Submit & view **blood requests**
- 🏥 Locate **nearby blood banks**
- 🤝 Become a **volunteer**
- 📊 Real-time data updates (JSON-based storage)
- 🧊 Beautiful UI with **Bootstrap 5**, **Glassmorphism**, and **3D effects**
- 🧾 Form validation and verified profiles
- 📱 Mobile responsive design
- 🔒 Privacy controls and secure backend

---

## 🛠️ Tech Stack

### Frontend:
- HTML5, CSS3, JavaScript (ES6)
- Bootstrap 5
- Tailwind CSS (for glass UI effects)

### Backend:
- Node.js
- Express.js
- JSON-based mock data (`/data/*.json`)
- CORS, body-parser, static middleware

### Others:
- Git & GitHub for version control
- Responsive video background and animation effects
